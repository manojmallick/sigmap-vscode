# Changelog — SigMap Cursor Plugin

All notable changes to the SigMap Cursor plugin are documented here.

## [1.0.0] — 2026-06-19

### Added
- Initial Cursor plugin release.
- MCP server wiring (`npx sigmap --mcp`) exposing 9 SigMap tools to the Cursor agent.
- `sigmap-context` rule directing the agent to use the signature map as primary context.
- `generate-context` skill for building and querying the signature map.
